- New: Send a book out. The button in the bottom right of the main screen is now Import / Export. Send a book out takes it a step at a time: pick the book and where it's going (Scrivener, Word, Google Docs, Obsidian or a Markdown folder), then the shape it arrives in. For Scrivener that's as Unwip has it, as it came in (for books brought in from Scrivener), or chapters only. For Word it's one file, a file per chapter, or a file for Vellum or Atticus.
- Before anything is saved, "What changes on the way out" lists what travels in a different form, each with a tick box: character sheet gear as a list on each character's page, the Story Bible as one document, maps as pictures, comments in Scrivener's notes (or a Comments file), and in Obsidian the first mention of each character or place becomes a [[link]].
- The last step counts the words in your manuscript here and the words that went out, so you can see every one made it.
- Inside a book, Export › No hard feelings… opens the same steps with that book already picked. Your book in Unwip never changes.
